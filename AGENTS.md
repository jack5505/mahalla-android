Инструкции агенту (Claude Code / CodeWhale). Грузятся в контекст каждой сессии,
поэтому файл держим коротким: здесь только то, без чего будет ошибка.
Всё остальное — по ссылкам ниже, читать по необходимости.

## Проект

Android-приложение **«Mahalla»** — суперприложение локальных услуг Узбекистана:
места рядом (еда, аптеки, больницы, кино, мастера, одежда), очереди,
бронирования, заказы, кошелёк, подписки, бизнес-панель.

**Kotlin + Jetpack Compose + Material 3**, нативный Android. iOS вне скоупа,
Flutter / React Native / KMP запрещены (`rules/tech-stack.md` в дизайн-репо).

Решения из ТЗ, не пересматривать без команды:

- макет **B «Focus»** утверждён; minSdk 26 / targetSdk 35; только **portrait**;
- тема тёмная + светлая по системе, **Dynamic Color выключен** (палитра — бренд);
- **uz по умолчанию** (`values/`), ru в `values-ru/`; шрифт Inter;
- базовый экран 393×852 dp; суммы и талоны — tabular numerals (`tnum`).

## Команды

```bash
./gradlew testDebugUnitTest     # юнит-тесты (163 класса)
./gradlew assembleDebug         # сборка
./gradlew lintDebug             # lint, warningsAsErrors включён
```

Эмулятора нет ни в CI, ни в песочнице — instrumentation-тесты не запускать.

## Окружение

**В CI** (`claude.yml` / `claude-dev.yml`) всё готово: JDK 17, Android SDK
(platform 35, build-tools 35.0.0), gradle-кэш.

**Локально** без этих переменных Gradle не стартует:

```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
export GRADLE_USER_HOME=/tmp/gradle-home    # песочница не пускает в ~/.gradle
export ANDROID_USER_HOME=/tmp/android-home  # AGP не пускают в ~/.android
```

SDK лежит внутри проекта в `.sdk/` (в `.gitignore`), `local.properties` уже
на него указывает. brew-gradle 9.7.0 сломан — только `./gradlew`.

Связка **AGP 8.7.3 + Gradle 8.11.1 + Kotlin 2.0.21 + JDK 17** проверена,
без необходимости не менять.

## Правила

- **Прогонять `testDebugUnitTest` и `assembleDebug` до пуша.** Не «перед PR», а
  до пуша. Три эпика подряд `main` был некомпилируемым (`Color.kt`, потом
  `Type.kt` + `MahallaApp.kt`) именно потому, что сборку откладывали.
- **Тесты обязательны** для любого функционала и входят в тот же коммит;
  результат прогона — в отчёте. Красные тесты = работа не готова.
- **Контракт бэкенда не выдумывать.** Нет подтверждения — свериться с
  `docs/API-CONTRACT.md`, при расхождении писать в отчёт, а не угадывать.
  Выдуманные эндпоинты уже дважды приводили к переделке вертикали.
- **Минимум кода сверх запроса.** Непонятно — спросить, не додумывать.
- **Секреты** — только через env, в код не писать.
- `rm -rf`, `sudo`, изменения вне рабочей папки — только по явной команде.
- **Git**: в облаке коммиты, ветки (`claude/*`, `claude-dev/*`) и PR делает
  `claude-code-action` от имени `claude[bot]`; прямо в `main` не пушить.
  Локальному агенту git — только по явной команде пользователя; force-push и
  `reset --hard` запрещены всегда (`.claude/settings.json`).

## Рабочий цикл

1. Прочитать задачу и то, на что она ссылается (`docs/`, дизайн-репо).
2. Сделать, написать тесты.
3. `./gradlew testDebugUnitTest && ./gradlew assembleDebug` — зелёные.
4. Коммит в свою ветку, PR, отчёт: что сделано, что прогнано и с каким
   результатом, что осталось и какие риски.

Открытые замечания и находки оформлять **issue**, а не абзацем в документации.

## Ждёт действия пользователя

Секреты и переменные в Settings → Secrets and variables → Actions:

- `MAPKIT_API_KEY` — без него на месте карты объяснение, а не тайлы;
- `SENTRY_DSN` — без него падения у пользователей невидимы;
- `DESIGN_REPO_PAT` — без него агент в CI работает без ТЗ и макетов;
- `BACKEND_IMAGE` / `BACKEND_PORT` / `BACKEND_HEALTH_PATH` — docker-бэкенд
  в `claude-dev.yml`.

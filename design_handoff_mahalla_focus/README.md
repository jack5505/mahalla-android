## Overview
Редизайн клиентской части суперприложения **Mahalla** (места рядом, очереди/талоны, брони, кошелёк, профиль) на основе утверждённого макета **B «Focus»**. Ключевая идея — одна **фокус‑карточка** сверху главной, которая отвечает на вопрос «что мне сейчас»: пока талона нет — ближайшее открытое место с кнопкой «Взять талон»; как только талон взят — та же карточка становится талоном (номер, сколько перед вами, ETA), а на вкладке «Очереди» появляется бейдж.

## About the Design Files
Файлы `*.dc.html` и `Mahalla — все экраны.html` — **дизайн‑референсы, сделанные в HTML** (интерактивные прототипы, показывающие вид и поведение). Это **не production‑код**. Задача — **воссоздать экраны в существующем Android‑проекте** (`jack5505/mahalla-android`, Kotlin + Jetpack Compose + Material 3) его средствами: `MaterialTheme`, `NavigationBar`, `ModalBottomSheet`, `Scaffold`, существующие `*Api.kt` и контракт из `docs/API-CONTRACT.md`. Ничего из HTML не переносить напрямую.

## Fidelity
**High‑fidelity.** Цвета, типографика, отступы, радиусы, копирайт и состояния финальные — воспроизводить точно (с поправкой на dp: макет 393×852 dp, 1 px в HTML = 1 dp).

Язык копирайта в макетах — русский; в приложении uz по умолчанию (`values/`), ru в `values-ru/`. Все строки ниже — для `values-ru`, uz‑перевод сделать зеркально.

### Радиусы
- Кнопки (filled/tonal/outlined): **20 dp** (pill при высоте 46–52 → `CircleShape`)
- Плитки категорий, карточка талона, «пусто»‑карточка, ряд «Mahalla+»: **16 / 24 / 24 / 20 dp**
- Фокус‑карточка: **28 dp**
- Шторка: **28 dp** сверху
- Поля ввода / чипы / плитка фото / карта: **12 / 8 / 12–16 / 16 dp**
- Индикатор активной вкладки: pill 56×30, радиус 15
- Бейдж на вкладке: 15×15, радиус 8, обводка 1 dp primary

### Отступы
- Горизонтальный отступ экрана: **20 dp** (онбординг — 24 dp)
- Вертикальный ритм: 18–22 dp между блоками, 9–12 dp внутри
- Высота шапки: ~76 dp (14 сверху / 11 снизу + 1 dp divider)
- Ряды списка: 13 dp сверху/снизу, divider 1 dp между рядами
- Минимальная зона нажатия: **44 dp**; основные кнопки 46–52 dp

### Тени
- Фокус‑карточка: `0 12 32 rgba(45,43,43,.22)`
- Шторка: `0 −8 24 rgba(29,27,32,.14)`
- Всё остальное — без теней (tonal elevation)

## Interactions & Behavior
- Навигация: 4 вкладки без анимации переключения; карточка места — push поверх текущей вкладки, «← Назад» возвращает.
- Взять талон (с главной или из карточки места): создать талон `A‑{очередь+12}`, перейти на «Очереди», snackbar «Талон взят · {место}  {номер}» 2,6 с; фокус‑карточка переключается в режим талона; бейдж «1» на вкладке.
- Обновить очередь: −2 «перед вами», ETA ≈ ahead × 2,2 мин (мин. 2); при 0 — snackbar «Ваша очередь — подойдите к окну».
- Отменить талон: snackbar «Талон отменён», карточка возвращается к «ближайшее место», бейдж исчезает.
- Фильтр категорий: мгновенный, счётчик «N из 6» обновляется; «Ещё» открывает полный список категорий (в прототипе — snackbar «Все категории  24 раздела»).
- Шторка: выбор дня сбрасывает слот; подтверждение без слота — ошибка; занятый слот — ошибка; успешная бронь добавляется в начало списка.
- Hover/pressed: тональные — затемнение на 8 % (`#e8deff` → M3 state layer); filled — state layer 12 % белого; ряды списка — фон `rgba(109,79,194,.06)` при нажатии. Focus — стандартный M3.
- Snackbar: фон `#2b2440`, текст 11.5 `#fdf8ff`, мета справа `#b9a3f0` tnum, r8, отступ 20 dp от краёв, 82 dp от низа (над nav bar), 2,6 с.
- Онбординг: назад по стрелке; «Продолжить»/«Готово» неактивны (цвет `#cac4d0`) до выполнения условия.

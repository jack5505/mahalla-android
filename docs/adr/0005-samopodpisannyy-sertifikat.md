# 0005. Доверие сертификату стенда по отпечатку

**Статус:** Принято (issue #32, поправлено ревью PR #33)

## Контекст

Тестовый бэкенд отдаёт самоподписанный сертификат — debug-сборка к нему
не подключалась.

## Решение

Доверие по **отпечатку конкретного сертификата**, и только в debug.

## Почему не иначе

- Отключать проверку целиком (`trustAllCerts`) нельзя: такой код регулярно
  утекает в release, и приложение становится открытым для MITM.
- `networkSecurityConfig` с `debug-overrides` — приемлемая альтернатива, но
  отпечаток в коде проще держать в одном месте вместе с адресом стенда,
  который вводится в приложении.

## Последствия

- **В release TLS-настройка не подменяется** — это ловило ревью PR #33.
- Сменился сертификат стенда — надо обновить отпечаток, иначе debug перестанет
  подключаться. Убрать вместе с переездом стенда на нормальный сертификат.

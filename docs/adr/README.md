# Решения по архитектуре (ADR)

Одно решение — один файл. Пиши сюда то, что **нельзя вывести из кода**:
почему выбрано это, что рассматривали ещё, чем за это платим.

Формат: контекст → решение → последствия → статус. Коротко, полстраницы.
Решение отменили — не удаляй файл, поставь статус «Заменено на NNNN».

Заводить ADR, когда: выбрали библиотеку или SDK, приняли схему хранения,
отступили от очевидного пути, или спор уже возникал второй раз.

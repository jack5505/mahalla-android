# 0001. Стек и рамки приложения

**Статус:** Принято (ТЗ, `design/android/TZ-ANDROID.md`)

## Контекст

Суперприложение локальных услуг для Узбекистана. Нужно было зафиксировать
платформу и рамки до начала вёрстки 35 экранов.

## Решение

Нативный Android: **Kotlin + Jetpack Compose + Material 3**.
minSdk 26 / targetSdk 35, только portrait.
Тема тёмная + светлая по системе, **Dynamic Color выключен**.
Языки: uz по умолчанию (`values/`), ru в `values-ru/`. Шрифт Inter.

## Почему не иначе

- Flutter / React Native / KMP запрещены `rules/tech-stack.md`: команда одна,
  вторая платформа вне скоупа, а кроссплатформа стоила бы доступа к нативным
  API (биометрия, MapKit, платёжные SDK).
- Dynamic Color выключен, потому что палитра — часть бренда: под Material You
  фирменные цвета подменялись бы обоями пользователя.
- minSdk 26 — граница, ниже которой не работают AndroidKeyStore в нужном
  режиме и часть Compose-поведения; охват при этом остаётся почти полным.

## Последствия

- Landscape не поддерживаем — экраны верстаются под 393×852 dp.
- Per-app languages доступны с API 33, для 26–32 нужен фолбэк
  (`LocaleContextWrapper` в `attachBaseContext`).
- Цвета берутся только из `MahallaColors`, системные акценты игнорируются.

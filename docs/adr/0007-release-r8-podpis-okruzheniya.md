# 0007. Release: R8 включён, подпись и окружения — из секретов

**Статус:** Принято (issue #17, эпик 13.4)

## Контекст

Release-сборка собиралась без минификации, без подписи и с адресом бэкенда,
зашитым в код. Правила ProGuard лежали в репозитории заранее, но никогда не
проверялись: включение R8 откладывалось, чтобы не начинать разбор падений в
рантайме посреди фичи.

## Решение

- `isMinifyEnabled = true` и `isShrinkResources = true` в release; правила — в
  `app/proguard-rules.pro`, каждое с объяснением, почему без него сломается.
- Подпись — из переменных окружения (секреты Actions) или `local.properties`.
  **Нет хранилища — сборка не падает**, release получается неподписанным.
- baseUrl остаётся привязанным к типу сборки, но перебивается переменной
  `API_BASE_URL_DEBUG` / `API_BASE_URL_RELEASE`.

## Почему не иначе

- **Не productFlavor под окружения**: вариантов сборки стало бы вчетверо
  больше ради одной строки, а стенды меняются чаще, чем схема сборки.
- **Не ронять сборку без ключа**: ровно так один незаполненный секрет ломал бы
  сборку всем, включая форки, — та же причина, по которой пустой
  `MAPKIT_API_KEY` и пустой `SENTRY_DSN` не ошибка.
- **Сериализаторы `uz.mahalla.**$$serializer` держим классом целиком**, хотя
  официальных правил kotlinx.serialization формально хватает: release нечем
  проверить в CI (эмулятора нет), а цена ошибки — приложение, падающее на
  первом ответе бэкенда у всех. В dex это десятки килобайт против 6 МБ кода.
- **`com.yandex.**` держим целиком** по документации MapKit: половина классов
  создаётся из C++ по имени через JNI, анализ достижимости этого не видит.

## Последствия

- `assembleRelease` проверяет, что R8 отработал, но **не** что приложение
  работает: R8 ломает только рантайм и только у пользователя. Перед выкладкой
  release прогоняется руками — вход, карта, список мест, заказ
  (`docs/RELEASE.md`).
- `mapping.txt` нужен, чтобы читать стектрейсы из Sentry: его надо сохранять
  на каждый выпущенный билд, иначе отчёт о падении показывает `a.b.c`.
- APK 108 МБ — это MapKit на четыре ABI (~103 МБ), кода после R8 всего 6 МБ.
  Пользователь качает около 26 МБ: Play режет AAB по ABI.
- Шаг `assembleRelease` в `ci.yml` не добавлен — правки `.github/workflows`
  агенту недоступны, это действие пользователя.

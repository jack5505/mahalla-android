# Тесты

Тесты обязательны для любого функционала и входят в тот же коммит.
Прогон: `./gradlew testDebugUnitTest` (сейчас 163 тест-класса).

## Грабли, стоившие времени

- **Один некомпилируемый тест роняет весь `compileDebugUnitTestKotlin`** —
  и тогда не выполняется ни один тест, молча. Так тесты эпика 2 не запускались
  ни разу. Если прогон подозрительно быстрый — смотри, компилируется ли модуль.
- **`SavedStateHandle.toRoute()` в JVM-тесте читает `null`.** Он разбирает
  типизированный маршрут через настоящий `Bundle`, а android.jar заглушен
  (`isReturnDefaultValues = true`) — все аргументы приходят пустыми, без ошибки.
  ViewModel, читающий аргументы маршрута, тестируй под **Robolectric**.
- **`Color.value` — не то, что кажется.** Compose кладёт sRGB-ARGB в старшие
  32 бита (в младших — id цветового пространства). Битовые сдвиги дают нули;
  каналы бери через `color.red / .green / .blue`.

## Соглашения

- Фейки — в `app/src/test/java/uz/mahalla/testutil/`, туда же фикстуры.
  Перед тем как писать новый фейк, посмотри, нет ли готового.
- `MainDispatcherRule` по умолчанию `StandardTestDispatcher` (иначе таймеры не
  двигаются виртуальным временем). Нужна немедленная отправка корутин —
  передавай `UnconfinedTestDispatcher()` явно.
- Сеть — MockWebServer. Покрывать не только успех: 401 + refresh, провал
  refresh, таймаут, битый JSON, неизвестные поля.
- DAO и DataStore — Robolectric.
- Тест должен ловить: временно внеси нарушение и убедись, что он краснеет.
  Тесты, сверяющие константу саму с собой, бесполезны — так уже вышло
  с `TouchTargetTest` и `ComponentStateTest`.

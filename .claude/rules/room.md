# Room

- **Миграции обязательны.** `fallbackToDestructiveMigration` из проекта убран
  (issue #64) и возвращать его нельзя: он стирает данные пользователя при
  каждом изменении схемы.
- Меняешь схему — в том же коммите: `version + 1`, объект `Migration`,
  регистрация в `MahallaDatabase` и тест миграции.
- **Room здесь — кэш, а не источник истины** (`docs/adr/0003-room-kak-kesh.md`).
  Сеть первична; кэш отдаётся при её отказе и только на первой странице.
  Перезаписывать кэш можно лишь запросом без единого фильтра.
- `exportSchema = false` — временно; включить обратно до первого релиза.
- DAO-тесты — под Robolectric.
